# Техническое задание

## Назначение

Создать библиотеку классов для перевода целых неотрицательных чисел между системами счисления с основаниями 2, 8, 10 и 16.

## Состав решения

- `NumSysLib` — библиотека классов.
- `NumSysDemo` — консольная программа для ручной проверки библиотеки через ссылку на проект.
- `NumSysLib.Tests` — автоматические тесты MSTest.
- `NumSysIntegrationDemo` — отдельная программа, подключающая собранный файл `NumSysLib.dll`.

## Архитектура библиотеки

- `ConverterBase` — общий абстрактный внутренний класс с алгоритмом преобразования.
- `Binary` — внутренний класс двоичной системы.
- `Oct` — внутренний класс восьмеричной системы.
- `DecimalNumber` — внутренний класс десятичной системы.
- `Hex` — внутренний класс шестнадцатеричной системы.
- `Adapter` — публичный класс с единым методом `Convert(value, fromBase, toBase)`.

## Валидация

Свойства `Value`, `FromBase` и `ToBase` проверяют входные данные в блоках `set`. Библиотека отклоняет пустые значения, неподдерживаемые основания и цифры, которых нет в исходной системе счисления. Консольная программа перехватывает исключения через `try-catch`.

## Проверка

Тесты проверяют переводы 2-10, 8-10 и 16-10 в обе стороны, прямой перевод 2-16 и обработку неправильных данных.

## Сборка и интеграция

Библиотека собирается командой `dotnet build -c Release`. После сборки `NumSysLib.dll` копируется в `NumSysIntegrationDemo/lib` и подключается через `HintPath` без ссылки на исходный проект библиотеки.
